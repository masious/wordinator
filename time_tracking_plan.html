Learning time plan (C15)

This is the working plan for learning time. It covers:

  • active time per lesson, per practice, and per activity;
  • typical lesson and practice times built from every learner who finished;
  • the lesson start gate;
  • weekly and monthly activity by category;
  • a personal daily goal and streak;
  • a home dashboard.

C15.0 moved every rule into its owning document. This file holds delivery steps only. Phase status is mirrored in docs/roadmap.md under Course phases.

Decisions settled with the user (2026-10-20)

  • Who counts. Medians include every learner who finished, the viewer included, with no minimum number of learners.
  • Median, not mean. Typical times are medians.
  • Reading median. It uses each learner's reading time up to their first completion. That snapshot is saved on the completion, so rereading doesn't move it.
  • Practice median. It uses each learner's time up to the save that finished the practice. A lesson's typical practice time is the sum of its practices' medians.
  • Reset. A lesson reset deletes the learner's reading, practice, and AI practice time for that lesson.
  • AI practices. Their time counts as practice time. Each AI practice carries a focus: grammar, vocabulary, reading, listening, or writing.
  • Practice again. Time in the Practice again dialog counts as practice time for its lesson.
  • Edited lessons keep the times recorded before the edit. No versioning.
  • Mission. It now allows a personal streak and a daily goal. There are still no points, rankings, leaderboards, or rewards.
  • Daily goal. Set in Settings, from 5 to 240 minutes per day, or no goal.
  • Start gate. An unstarted lesson shows its faded beginning with Start reading this lesson. Pressing it starts the lesson and the reading clock.
  • Dashboard. It uses the existing tokens only, with no new colours.

# Noto animated emoji

Still artwork (`<codepoint>.svg`) and Lottie animations (`<codepoint>.json`) from Google's
[Noto Animated Emoji](https://googlefonts.github.io/noto-emoji-animation/), downloaded from
`https://fonts.gstatic.com/s/e/notoemoji/latest/<codepoint>/{emoji.svg,lottie.json}` on 2026-10-10.

They are kept here so the app serves them from its own origin (see `docs/security-and-privacy.md`). Only the lesson overview
prototype uses them, and only development builds include them (`../notoEmoji.ts`). Confirm the licence and its attribution
requirements on the Noto Animated Emoji page before any production use.
